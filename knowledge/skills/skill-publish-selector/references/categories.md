# WorkBuddy 技能分类（categories）全表

| id | 中文 | 英文 | 适合发布的技能类型 |
|---|---|---|---|
| opc-solo-business | OPC·一人公司 | OPC · Solo Business | 面向独立开发者 / 一人公司 / 创业者的产品、商业、全栈落地类技能 |
| collaboration | 办公协同 | Collaboration | 文档协作、会议、项目管理、团队流程、同步协作类 |
| development-tools | 开发工具 | Development Tools | 软件开发 / 代码 / 接口 / 测试 / 需求工程 / 技术流程类 |
| investment-finance | 投资理财 | Investment & Finance | 金融数据、行情分析、理财建议、投资研究类 |
| productivity-tools | 效率工具 | Productivity Tools | 通用提效、脚本批处理、信息整理、个人效率类 |
| content-creation | 内容创作 | Content Creation | 写作、文案、新媒体、设计、视频、口播脚本类 |
| news-information | 信息资讯 | News & Information | 新闻聚合、热点监控、舆情、行业资讯类 |
| education-learning | 教育学习 | Education & Learning | 教学辅助、课程设计、学习辅导、知识讲解类 |
| data-analysis | 数据分析 | Data Analysis | 统计分析、BI、报表、数据清洗/可视化类 |
| website-deployment | 网站部署 | Website Deployment | 网站建设、页面开发、上线部署运维类 |
| lifestyle-services | 生活服务 | Lifestyle Services | 日常生活场景工具、本地生活类 |
| business-operations | 商业运营 | Business Operations | 电商、营销推广、运营策略、增长类 |
| knowledge-learning | 知识与学习 | Knowledge & Learning | 知识管理、阅读笔记、个人成长、资料库类 |

## 主分类对照速查

按技能功能域选「主分类」，可再加 1~2 个「扩展分类」覆盖目标用户场景。

| 功能域关键词 | 主分类 | 可选扩展 |
|---|---|---|
| 软件、代码、接口、测试、PRD、需求、技术文档 | development-tools | opc-solo-business / productivity-tools |
| 网站、前端、部署、上线、运维 | website-deployment | development-tools |
| 写作、文案、公众号、新媒体、短视频脚本、设计 | content-creation | news-information / business-operations |
| 周报、日志、会议纪要、文档流程 | collaboration | productivity-tools |
| 自动化、批处理、信息提取、小工具 | productivity-tools | development-tools |
| 数据、统计、报表、BI、可视化 | data-analysis | development-tools |
| 行情、投资、理财、金融 | investment-finance | news-information |
| 教学、课程、学习计划 | education-learning | knowledge-learning |
| 资讯、舆情、监控 | news-information | knowledge-learning |
| 电商、营销、运营 | business-operations | content-creation |
